# Netflix Clone

Proyecto académico: una página web sencilla que consume la API de [TMDB](https://www.themoviedb.org/) para mostrar un catálogo de películas populares, similar a la interfaz de Netflix.

## Cómo ejecutarlo

1. Consigue una API key gratuita en https://www.themoviedb.org/settings/api
2. Abre `script.js` y reemplaza `TU_API_KEY_AQUI` con tu propia key.
3. Abre `index.html` en tu navegador (doble clic, o usando una extensión como "Live Server" en VS Code).

## Estructura

- `index.html` — estructura de la página
- `style.css` — estilos visuales (tema oscuro tipo Netflix)
- `script.js` — lógica que consume la API de TMDB y pinta las tarjetas de películas
